# jimaku

Web Speech APIを使用したリアルタイム音声認識Webアプリケーションであり、拡張現実（AR）の字幕表示と併用するように設計されています。

## デモ

**https://code4fukui.github.io/jimaku/**

## 機能

*   **リアルタイム文字起こし**: 話している音声をリアルタイムでテキストに変換します（認識途中の結果も表示されます）。
*   **言語サポート**: 日本語（`ja`）と英語（`en`）の音声認識に対応しています。
*   **AR対応インターフェース**: オーバーレイ表示に適した高コントラスト（黒背景に白文字）の画面を備えています。
*   **レスポンシブ表示**: テキストサイズがビューポートの幅に合わせてスケーリングされます（`font-size: 2.5vw`）。
*   **フルスクリーンモード**: 余計なUIを隠し、没入感のある表示に切り替えることができます。

## 使い方

1.  [デモページ](https://code4fukui.github.io/jimaku/)を開きます。
2.  ドロップダウンメニューから希望する言語（`日本語`または`English`）を選択します。
3.  `スタート`ボタンをクリックしてマイク入力を開始します。
4.  話しかけると、認識されたテキストが画面下部に表示されます。
5.  `ストップ`ボタンをクリックして音声認識を終了します。
6.  `最大化`ボタンをクリックするとフルスクリーンモードになります。ボタンは自動的に非表示になります。

## 技術とデータプライバシー

このアプリケーションは、モダンWebブラウザに組み込まれている**Web Speech API**を利用しています。

ブラウザのAPI実装によっては、音声処理のために音声データがクラウドベースのサービスに送信される場合があります。この点にご留意の上、本アプリケーションをご利用ください。
